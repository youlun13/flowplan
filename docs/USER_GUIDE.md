# FlowPlan 使用手冊（第一階段）

## 第一次打開

- 新裝置會先看到歡迎畫面：「用 Google 登入」會載入你在其他裝置的資料（像一般 App 一樣）；「先在這台裝置使用」則資料只留在這台。
- 接著是五頁導覽（今日 / 任務 / 日曆 / 狀況 / 紀錄），看完或略過都行；設定 → 使用說明可以再看一次。沒有示範資料。
- 「今日」頁會是空的：按「新增任務」加幾件今天要做的事，下一步卡片就會出現。
- iPhone：用 Safari 開啟後點「分享 → 加入主畫面」。有登入的話兩邊會同步；沒登入則主畫面 App 與 Safari 分頁是兩份資料。
- 先到「設定」把可工作時段、睡眠保護、行程前後緩衝改成你的實際習慣，這些決定「可用時間」怎麼算。

## 每天怎麼用

**早上（1 分鐘）**

- 開「今日」。上方切換今天的精力（高 / 中 / 低）。
- 如果有「逾期未處理」，逐項決定：排到今天 / 延到明天 / 編輯（拆解）/ 取消。它們不會自己消失。
- 看「下一步做什麼」，按「開始」就會同時開始一筆實際紀錄。

**白天**

- 做完一件事：在「今日」按「完成」，或在任何清單勾選。
- 臨時有事：到「日曆」新增固定行程；今天的可用時間與時間軸立刻重算。
- 換一件事：到「紀錄」輸入「現在開始做什麼」按開始，上一筆會自動結束。
- 沒計時也沒關係：晚上到「紀錄」看空白時段，點「補登」填幾點到幾點做了什麼。

**晚上（2 分鐘）**

- 「紀錄」頁看今天實際花了多少時間在哪些事。
- 「任務」頁把明天要做的事設好「哪天做」。新增任務只要打標題 → 選今天 / 明天 → 新增，三步。

## 任務欄位怎麼填

| 欄位 | 什麼時候才需要填 |
|---|---|
| 哪天做 | 想排進某一天就填；不填會進「未排日期」 |
| 優先級 | 高 = 不做會出事；中 = 應該做；低 = 有空再做 |
| 預估分鐘 | 粗估即可，之後實際紀錄會累計真實工時方便校正 |
| 截止時間 | 只填真正的死線；系統用它算緊迫度，不要把「想做的日期」填在這裡 |
| 最低工時 / 最低成果 | 第二階段時間不夠會提出縮減版本；現在先填也可以 |
| 要先完成的任務 | 填了之後，前置沒完成，這個任務就不會出現在「下一步」 |

## 固定行程

- 每週的課：新增時打開「每週重複」，勾星期幾，填「重複到」學期結束日。
- 某一週停課：點那一次 → 「刪這一次」，其他週不受影響。
- 修改重複行程會套用到整個系列。

## 備份

- 設定 → 「匯出 JSON 備份」，存到 iCloud Drive 或任何地方。
- 換裝置 / 從 Safari 搬到主畫面 App：匯出後在另一邊「匯入 JSON（取代）」。
- 超過 7 天沒備份，「今日」頁會提醒。

## 規劃今天與「我遇到狀況了」

- 「今日」頁的下一步卡片在還沒排程時顯示「建議」；按「規劃今天」會算出今天剩下時間的安排，選一個方案按「就這個」才會寫入。套用後卡片會變成「已套用的排程」，時間軸左欄會出現綠色區塊。
- 遇到狀況時按「我遇到狀況了」。可以先用一句話描述（「我睡到十一點」「下午三點到五點臨時有事」「線代習題寫完了」「現在很累」「報告超時還要 40 分鐘」），按「解析」：先用內建規則理解，看不懂才呼叫 AI（需在設定開啟）；理解結果會先給你確認。
- 或直接選一種：睡過頭（填起床時間）、臨時有事（填幾點到幾點，套用後會自動加進日曆）、精力變化、提早完成、超時（還需要幾分鐘）、需要休息。按「看看怎麼辦」只回答一件事——**現在要做什麼**：
  - 「拚了」：直接做規則引擎排出來最重要（通常也最難）的那件——做什麼、幾點到幾點、為什麼。
  - 「先喘口氣」：先休息 15 分鐘站起來動一動，回來先做手上最輕鬆的一件（精力需求最低、時間最短），其餘自動重排；有截止時間的事仍會在截止前排回去。你已經選「需要休息」時，這張會變成「先做輕鬆的」。
  - 想看細節再展開「細節」，只有兩樣：套用後今日安排（任務區塊和固定行程、休息排在一起）、缺點（做不完的、趕不上截止的、只做最低版本的、被改時間的；排不下的可直接「延到明天」）。
  - 按「就這個」套用；「都不要，保留原計畫」什麼都不會改。
- 套用後卡片下方會出現「撤銷」，可以回到套用前。
- 區塊不是鬧鐘：時間過了不會自動消失，再按一次「規劃今天」就會重排剩下的。

## AI 助手（選用）

- 設定 → AI 助手：啟用、供應商 Claude、Worker 網址、通關密語、模型、每日上限；「測試連線」會確認 Worker 是否設好金鑰。設定步驟見 `docs/API_SETUP.md`。
- 送給 AI 的只有你那句描述、現在時刻、今天的任務標題與行程時間。回答經結構驗證與任務 id 核對，不合法就拒絕並告訴你。
- 預覽頁可按「請 AI 用白話說明」，算一次請求。
- 沒有 AI、額度用完、Worker 掛了：全部自動退回規則解析與表單，核心功能不受影響。

## 跨裝置同步（選用）

- 單人：設定 → 跨裝置同步 → 啟用 → 儲存。第一台裝置會把全部資料推上你的 Cloudflare KV；第二台啟用後按「立即同步」拉下來。之後有變更幾秒內自動推送，回到前景、重新上線、每 90 秒自動拉取。
- 同一筆資料兩台都改過，以較新的為準；刪除也會同步到另一台。這台裝置還沒推送的變更不會被雲端覆蓋。
- 「檢查雲端」看雲端版本與筆數；「以雲端為準覆蓋本機」會清掉本機再載入；「刪除雲端資料」只刪雲端。
- 離線時照常可用，變更會排隊，恢復連線後推送。正式版可加入主畫面離線開啟；有新版本時上方會出現「更新」。

## 登入與多人使用（選用）

- 擁有者把你的 email 加進允許清單後：設定 → 帳號 → 「用 Google 登入」→ 選帳號 → 回到 App 會顯示「已用 xxx 登入，同步已開啟」。登入後 AI 助手與同步都不需要通關密語，資料存在你自己的空間，別人看不到。
- 第二台裝置一樣登入：那台沒有自己的資料時會直接換成你雲端的資料與設定；已有自己的資料則合併。登入有效 60 天，期間使用會自動延長。
- 「登出」：資料留在這台裝置，同步與 AI 停用。「登出並清除此裝置資料」：借用別人的裝置時用。
- 同一台裝置換帳號登入時會先問要不要清掉本機資料；取消就維持原帳號。
- 看到「不在允許清單」：請擁有者在 Cloudflare Worker 的 `ALLOWED_USERS` 加上你的 email。
- 從主畫面的 FlowPlan 登入若停在瀏覽器畫面：登入頁會給一段「登入碼」，回 App → 設定 → 帳號 → 「貼上登入碼」。

## 紀錄 → 週

- 紀錄頁上方切到「週」：每天各分類記錄了多少時間、最近 28 天完成趨勢。
- 「預估準不準」：完成任務 ≥ 3 筆後，顯示實際 / 預估的中位數係數（依精力分組）。規則引擎會用這個係數調整預估工時，並在判斷過程裡說明；不想要可在設定 → 決策偏好關閉。
- 「一直被延後的」：延後次數最多的未完成任務，提醒你拆小或放棄。
