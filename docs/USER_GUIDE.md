# FlowPlan 使用手冊（第一階段）

## 第一次打開

1. 會看到一組示範資料（標題都有「（示範）」）。看懂每個區塊在做什麼後，到 **設定 → 刪除示範資料** 一鍵清掉。
2. iPhone：用 Safari 開啟後點「分享 → 加入主畫面」。之後**固定從主畫面開**，因為 Safari 分頁與主畫面 App 是兩份獨立資料。
3. 到 **設定** 把可工作時段、睡眠保護、行程前後緩衝改成你的實際習慣。這些決定「可用時間」怎麼算。

## 每天怎麼用

**早上（1 分鐘）**

- 開「今日」。上方切換今天的精力（高 / 中 / 低）。
- 如果有「逾期未處理」，逐項決定：排到今天 / 延到明天 / 編輯（拆解）/ 取消。它們不會自己消失。
- 看「下一步做什麼」，按「開始」就會同時開始一筆實際紀錄。

**白天**

- 做完一件事：在「今日」按「完成」，或在任何清單勾選。
- 臨時有事：到「日曆」新增固定行程；今天的可用時間與時間軸立刻重算。
- 換一件事：到「紀錄」輸入「現在開始做什麼」按開始，上一筆會自動結束。
- 沒計時也沒關係：晚上到「紀錄」看空白時段，點「補登」填幾點到幾點做了什麼。

**晚上（2 分鐘）**

- 「紀錄」頁看今天實際花了多少時間在哪些事。
- 「任務」頁把明天要做的事設好「哪天做」。新增任務只要打標題 → 選今天 / 明天 → 新增，三步。

## 任務欄位怎麼填

| 欄位 | 什麼時候才需要填 |
|---|---|
| 哪天做 | 想排進某一天就填；不填會進「未排日期」 |
| 優先級 | 高 = 不做會出事；中 = 應該做；低 = 有空再做 |
| 預估分鐘 | 粗估即可，之後實際紀錄會累計真實工時方便校正 |
| 截止時間 | 只填真正的死線；系統用它算緊迫度，不要把「想做的日期」填在這裡 |
| 最低工時 / 最低成果 | 第二階段時間不夠會提出縮減版本；現在先填也可以 |
| 要先完成的任務 | 填了之後，前置沒完成，這個任務就不會出現在「下一步」 |

## 固定行程

- 每週的課：新增時打開「每週重複」，勾星期幾，填「重複到」學期結束日。
- 某一週停課：點那一次 → 「刪這一次」，其他週不受影響。
- 修改重複行程會套用到整個系列。

## 備份

- 設定 → 「匯出 JSON 備份」，存到 iCloud Drive 或任何地方。
- 換裝置 / 從 Safari 搬到主畫面 App：匯出後在另一邊「匯入 JSON（取代）」。
- 超過 7 天沒備份，「今日」頁會提醒。

## 規劃今天與「我遇到狀況了」

- 「今日」頁的下一步卡片在還沒排程時顯示「建議」；按「規劃今天」會算出今天剩下時間的完整排程，預覽後按「套用新計畫」才會寫入。套用後卡片會變成「已套用的排程」，時間軸左欄會出現綠色區塊。
- 遇到狀況時按「我遇到狀況了」，選一種：睡過頭（填起床時間）、臨時有事（填幾點到幾點，套用後會自動加進日曆）、精力變化、提早完成、超時（還需要幾分鐘）、需要休息。按「看看怎麼辦」會看到：
  - 建議的下一步
  - 變更：新增 / 移動 / 縮短 / 移除 / 延後，以及加入的行程
  - 套用後的完整排程（保留的區塊會標「保留」，縮短的標「最低」）
  - 排不下的任務和原因，可以直接按「延到明天」
  - 「規則引擎的判斷過程」展開可看每一步的理由
- 「保留原計畫」什麼都不會改。套用後卡片下方會出現「撤銷」，可以回到套用前。
- 區塊不是鬧鐘：時間過了不會自動消失，再按一次「規劃今天」就會重排剩下的。
